# ランダムテレポート

EcoLifeAssist が `/rtp` を提供する。通常プレイヤーの `/rtp` は現在のワールドで実行し、運営は `/rtp world <ワールド>` または `/rtp player <名前> <ワールド>` を使う。後者はコンソールからも実行でき、資源ワールドの初回入場に使用する。

設定はプラグインデータの `rtp.yml`。既定値は従来の BetterRTP と同じ中心座標 (0, 0)、半径 10～3000、最大32回の探索、600秒のクールダウン、5秒の待機。通常のRTPはプレイヤーごとに初回の成功だけ無料、以降は成功1回につき100S（`price`）をVault経済から支払う。残高不足や経済連携の停止時は移動せず、テレポート失敗時は返金する。プレイヤーがワールドを移動したり切断したりすると探索を中止する。コンソールと運営によるプレイヤー指定は料金・待機・クールダウンを適用せず、初回無料枠も消費しない。クールダウンは `rtp-cooldowns.yml`、初回利用は `rtp-free-used.yml` に保存して再起動後も維持する。

探索では対象チャンクを非同期で読み込み、床と足元・頭上、周囲の水・溶岩・火・危険ブロックを確認する。ネザーでは岩盤天井を避けて空間を探す。到着先が見つからない場合、元の地点に留まる。ワールド境界の外には移動しない。保護領域との連携は従来のサーバー設定でも無効だったため実装していない。

通常プレイヤー権限は `ecolife.rtp`。別ワールド指定は `ecolife.rtp.world`、他のプレイヤーの移動は `ecolife.rtp.admin` で、後二者は運営が既定。`/ecolife reload` で RTP 設定も再読み込みする。

隔離 Paper 検証は `python3 scripts/test-rtp-paper.py`。テスト用 Player アダプタでコマンド、着地点、初回無料、100S決済、移動失敗時の返金、待機、クールダウン、管理者の代行移動、再起動後の記録を確認する。実クライアントの画面表示や、資源ワールド初回入場の Skript 連携は別途確認する。
