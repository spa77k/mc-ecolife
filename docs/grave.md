# お墓

死亡時に落ちる持ち物と経験値を預かり、本人だけが取り出せるようにする。期限が過ぎたら中身をその場に落とし、お墓がない場合と同じ状態に戻す。

## 動き

- 死亡時のドロップ（`PlayerDeathEvent` の drops）と、落ちる経験値（バニラと同じ量）をお墓に移す。keepInventory が有効なとき、`excluded-worlds` のワールド、落とす物も経験値もないときは作らない。
- ドロップを死亡直前の持ち物と突き合わせ、元のスロット番号を記録する。他プラグインが足したドロップはスロットなしで預ける。
- 本人がお墓を右クリック（統合版はタップ）または左クリックすると取り出せる。空いている元のスロットへ戻し、埋まっていれば持ち物の空きへ入れ、それでも入らなければ足元に落とす。経験値も戻す。
- 本人以外は取り出せない。`ecolife.grave.admin` を持つ運営は取り出せる（元のスロットには戻さない）。
- 期限（`expire-minutes`、既定15分）が過ぎると、中身と経験値をお墓の位置に落とす。サーバー停止中も時間は進む。落ちたアイテムは普通のドロップと同じく時間がたつと消える。
- 置き場所は足元から下へたどった最初の固体か液体の上。奈落ではその真上で一番高いブロックの上、それもなければワールドのスポーン地点。
- `/grave` で自分のお墓の場所と残り時間、`/grave all` で全員ぶんを表示する。

## 保存と目印

- 中身の正本は `plugins/EcoLifeAssist/graves.yml`。作成時と取り出し・期限切れの前に書き出す（取り出しでは先に記録を消してから渡し、二重に渡さない）。
- ワールドには目印として、墓石の `ItemDisplay`、名前と残り時間の `TextDisplay`、クリック判定の `Interaction` を置く。どれも壊れない。
- チャンクの読み込み時に、記録のない目印は消し、目印が消えたお墓は作り直す。

## テクスチャ

- `assets/grave/grave.png` が32×32のドット絵。Codex の画像生成で作り、マゼンタの背景を透過した。
- `python3 scripts/build-phone-packs.py` が、スマホと同じJava用パック（`target/ecolife-phone-java.zip`）に `ecolife:grave` のアイテムモデルとして入れる。墓石は `COBBLESTONE_WALL` に `item_model` を付けて表示するため、パックを読み込めない場合は丸石の塀に見える。
- Geyser は `ItemDisplay` を統合版へ送らないため、統合版では墓石が見えず、名前と残り時間の表示とクリック判定だけになる。統合版用パックとGeyserのマッピングは変えていない。

## テスト

`python3 scripts/test-grave-paper.py` が隔離Paper（`target/grave-paper-smoke`、`127.0.0.1:25585`、`GRAVE_TEST_PORT` で変更）で、作成・スロット復元・本人以外の拒否・運営の取り出し・期限切れの落下・保存と読み直し・keepInventory・奈落の置き場所・目印の掃除と作り直しを確かめる。テスト用Playerは本物のプレイヤーではない。実クライアントでの墓石の見た目、統合版でのタップは別途確認が必要。
