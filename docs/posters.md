# ポスターの運営ガイド

## 合意した仕様（2026-09-22）

EcoLifeAssistへの機能追加として、運営が用意した画像を一般プレイヤーが一覧から選び、自分の建築に飾れるようにする。画像の直接投稿機能は設けない。追加要望は既存のフィードバック機能で受け付ける。

## プレイヤーの使い方

1. `/poster` で一覧を開き、欲しいポスターを左クリックする。
2. 地図一式を無料で受け取る。全タイル分の空き枠が必要（2×2なら4枠）。額縁は配布しない。
3. 壁に額縁を並べ、地図の名前にある「行・列」の順に入れる。左上が1行1列。地図を回転させずに並べる。

1枚の地図は128×128ピクセル。サイズは1×1から4×4ブロックまで。画像の縦横比は維持し、余白と透過部分は黒になる。Minecraftの地図色に変換されるため、元の画像と色は完全には一致しない。細かい文字は大きなサイズのポスターで使う。

通常の額縁設置操作を使うため、設置・破壊はサーバー既存の建築保護ルールに従う。独自の設置処理で保護を迂回しない。配布は何度でも可能。同一画像・同一サイズは全ユーザーで同じ地図IDを共有する。

## 画像の登録

初回起動時に `plugins/EcoLifeAssist/posters/` が作られる。初期カタログは空。実際に公開する画像は運営が用意する。

1. PNGまたはJPEGを `posters/images/` に配置する。
2. `posters/catalog.yml` に登録する。
3. ゲーム内またはコンソールから `/poster reload` を実行する。

```yaml
posters:
  neko:
    title: "ネコと和解せよ"
    file: "neko.png"
    width: 2
    height: 2
    enabled: true
  notice:
    title: "お知らせ"
    file: "notice.jpg"
    width: 1
    height: 2
```

- IDは英小文字・数字・`_`・`-`で1〜48文字。表示名は1〜80文字。
- 登録数は最大128種類。GUIは45件ずつページ表示する。
- ファイルは10MB以下、1600万画素以下。外部URLやimagesの外にあるファイルは読み込まない。
- 読み込みは非同期。読み込み中は現在の一覧が使える。成功すると開いていたポスター一覧を閉じる。
- 設定や画像に問題が1件でもあれば更新全体を中止し、直前の一覧を維持する。初回起動時の失敗なら空のまま。詳細はサーバーログで確認する。
- ポスターの再読み込みは `/poster reload` 専用。`/ecolife reload` は従来機能の設定用。
- `enabled: false` または設定削除で新たな配布を止める。すでに受け取った地図は引き続き表示される。
- 画像やサイズを変更すると、新しく受け取る地図に変更が反映される。設置済みの地図は元の画像を保持する。更新したい人は新しい地図を受け取って差し替える。

## 権限

| 権限 | 既定 | 内容 |
| --- | --- | --- |
| `ecolife.poster` | 全員 | 一覧表示・地図の受け取り |
| `ecolife.poster.admin` | OP | カタログ再読み込み |

## 保存・バックアップ

`posters/maps.yml` が画像・サイズと地図IDの対応、`posters/cache/` が取得済みポスターの描画画像。運営が取り下げた画像も既存の飾りを維持するため残す。これらを手動で削除しない。

サーバー停止後に、`posters/` 全体とワールドの地図データを一緒にバックアップする。片方だけ復元するとIDの対応が崩れる。保存データを読み込めない場合、ポスター機能を停止してログに記録し、ログインボーナスなど他機能は継続する。復旧後はサーバーを再起動する。

## 検証

- `mvn -B package`: 画像の分割順・縦横比・余白・入力制限と既存単体テスト。
- `python3 scripts/test-poster-paper.py`: Paper 26.1.2 / Java 25、`target/poster-paper-smoke`、`127.0.0.1:25580`。テスト用Playerで一覧・ページ切替・権限・満杯時の配布拒否・タイル配布・ID再利用・再起動後の描画復元・一覧から取り下げた画像の保持を確認する。
- テスト用Playerは実クライアントではない。Java/Bedrockクライアントの画面での見え方、額縁への配置、既存の土地保護プラグインとの組み合わせは別途実機確認が必要。

API参照: [Paper MapView](https://jd.papermc.io/paper/26.1.2/org/bukkit/map/MapView.html)、[MapRenderer](https://jd.papermc.io/paper/26.1.2/org/bukkit/map/MapRenderer.html)。
