# スマホ

一般プレイヤー向けのコマンド案内。右クリックで開く配布アイテムを入口とし、操作は既存プラグインのコマンド・GUIへ引き継ぐ。プレイヤー権限で実行するため、各機能の制限はそのまま働く。

## 配布と回復

- 初回を含むログイン時に、手持ちとエンダーチェストにスマホがなければ1個渡す。死亡後も同様。
- 持ち物が満杯なら配布しない。`/phone` でGUIを開け、空きを作って `/phone get` で受け取れる。
- 誤って捨てないよう、スマホのドロップはキャンセルする。紛失時は `/phone get`。
- 専用テクスチャを読み込めない場合は時計として見えるが、名前と機能は利用できる。

## メニュー

トップの目立つ位置にオークションを置く。売り買い、移動、遊びと記録、案内と相談のカテゴリから、次の一般向け機能へ進む。

| 分類 | 内容 |
| --- | --- |
| 売り買い | オークション、出品、保管庫、自分の出品・入札、依頼所、自分の依頼、QuickShop一覧、残高、送金の使い方 |
| 移動 | ロビー、RTP、ホーム、ホーム登録、案内所、2か所目のホームの使い方 |
| 遊びと記録 | 職業一覧・記録・日次クエスト、レベル、進捗、土地保護、ログインボーナス、招待、ポスター、案内所 |
| 案内と相談 | 遊び方、ルール、フィードバックの使い方、ショップの作り方、土地保護の使い方 |

金額が発生するホーム登録は確認画面を挟む。引数が必要な送金・フィードバックはコマンドの使い方を表示する。管理者コマンドは載せない。既存の `/menu` からもスマホ画面を開ける。

## テクスチャ

`assets/phone/smartphone.png` が共通の32×32ドット絵。`python3 scripts/build-phone-packs.py` でJava用 `target/ecolife-phone-java.zip` と統合版用 `target/ecolife-phone-bedrock.mcpack` を生成する。Javaパックは `ecolife:smartphone` のアイテムモデル、統合版はGeyserのカスタムアイテムマッピングで時計からスマホへ変換する。Javaパックの対象はMinecraft 26.1（リソースパック形式84）。

リリースではJava用zipを既存の `v1.0.0` に添付し、インフラのComposeでURLとSHA-1を固定する。統合版用mcpackとマッピングは `spsmc-infra/plugins/Geyser-Spigot/` にGit管理し、起動時に同期する。リリースやインフラ設定の更新だけでは本番サーバーに反映されない。

`python3 scripts/test-phone-paper.py` は隔離Paperで配布・重複防止・メニュー生成を検証する。Java/Bedrock実クライアントでの描画、Geyserのテクスチャ配信、GUIクリックは別途実機確認が必要。
