# スマホ

一般プレイヤー向けのコマンド案内。右クリックで開く配布アイテムを入口とし、操作は既存プラグインのコマンド・GUIへ引き継ぐ。プレイヤー権限で実行するため、各機能の制限はそのまま働く。

## 配布と回復

- 初回参加時だけ、手持ちとエンダーチェストにスマホがなければ1個渡す。2回目以降のログインと死亡後は自動配布しない。
- 持ち物が満杯なら配布しない。案内係の「スマホを受け取る」または `/phone get` で後から受け取れる。
- スマホは普通のアイテムと同様に捨てられ、死亡時も通常のドロップ設定に従う。紛失時は案内係または `/phone get` を使う。アイテムがなくても `/phone` でGUIを開ける。
- 専用テクスチャを読み込めない場合は時計として見えるが、名前と機能は利用できる。

## メニュー

トップはアプリの一覧にする。`Spa Job` は職業一覧、`Spazon` はオークションとAdminShop、`Spa Mail` はフィードバック入力、`SpaMap` はロビー移動を開く。`その他の機能` から売り買い、移動、遊びと記録、案内と相談へ進む。

| 分類 | 内容 |
| --- | --- |
| 売り買い | オークション、出品、保管庫、自分の出品・入札、依頼所、自分の依頼、QuickShop一覧、残高・ランキング、送金の使い方 |
| 移動 | ロビー、RTP、ホーム、ホーム登録、案内所、2か所目のホーム、プレイヤー間の移動申請・許可・拒否・取消 |
| 遊びと記録 | 職業一覧・記録・日次クエスト・ランキング、レベル、進捗、土地保護、ログインボーナス、招待、ポスター、案内所 |
| 案内と相談 | 遊び方、ルール、フィードバック、個別メッセージ、ショップ・土地保護の使い方 |

金額が発生するホーム登録は確認画面を挟む。`Spa Mail` はチャット入力を会話モードで受け取り、既存の `/feedback` コマンドへ渡す。移動画面の「相手へ移動を申請」「相手を呼ぶ申請」はオンラインの相手を一覧から選び、`/tpa`・`/tpahere` を実行する。申請の許可・拒否・取消も同じ画面から操作する。送金など相手や金額が必要なその他の操作はコマンドの使い方を表示する。管理者コマンドは載せない。既存の `/menu` からもスマホ画面を開ける。

スマホを手に持ったまま「オークションに出品」を選んだ場合は出品操作を開始せず、持ち替えを案内する。AuctionHouse 側でもスマホの識別データを確認して出品開始・確定を拒否する。出品したい物を手に持ち替えてから `/ah sell` を実行する。

## テクスチャ

`assets/phone/smartphone.png` が共通の32×32ドット絵。`python3 scripts/build-phone-packs.py` でJava用 `target/ecolife-phone-java.zip` と統合版用 `target/ecolife-phone-bedrock.mcpack` を生成する。Javaパックは `ecolife:smartphone` のアイテムモデル、統合版はGeyserのカスタムアイテムマッピングで時計からスマホへ変換する。Javaパックの対象はMinecraft 26.1（リソースパック形式84）。

リリースではJava用zipを既存の `v1.0.0` に添付し、インフラのComposeでURLとSHA-1を固定する。統合版用mcpackとマッピングは `spsmc-infra/plugins/Geyser-Spigot/` にGit管理し、起動時に同期する。リリースやインフラ設定の更新だけでは本番サーバーに反映されない。

`python3 scripts/test-phone-paper.py` は隔離Paperで配布・重複防止・メニュー生成・移動申請のGUI操作を検証する。Java/Bedrock実クライアントでの描画、Geyserのテクスチャ配信、実プレイヤー間の申請は別途実機確認が必要。
